Secure Authentication Lab

SecureAuth is a defensive Flask and SQLite authentication service demonstrating salted password hashing, strict server-side input validation, rate limiting, CSRF protection, and hardened cookie-based sessions.

Password Storage

Passwords are validated server-side and hashed using Werkzeug's salted scrypt algorithm before storage. Plaintext credentials are never saved or logged.

Abuse & Enumeration Defense

Flask-Limiter throttles repeated login and registration attempts, while generic error messages and constant-time dummy checks prevent account enumeration.

Hardened Cookie Sessions

Authenticated sessions rotate on login, enforce HttpOnly and SameSite=Lax cookie flags, and automatically expire after inactivity.
